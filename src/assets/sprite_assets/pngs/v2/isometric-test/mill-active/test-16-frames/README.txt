Mill farmer downward stroke — 16-frame draft

All PNGs are 1024 x 1024 with transparency. Each contains the complete mill, farmer and lever. Frame 01 and 16 use the two user-approved endpoint sprites, normalized to the common canvas. Frames 02–15 were generated individually using the built-in image generation tool. Prompts are in prompts.txt.

The stationary mill layer is copied unchanged into every frame. Foreground layers are registered at the rope collar / mill pivot.

Known limitations: generated farmer scale, lever length/thickness, hand grip distances and foot contact vary between frames. This is a draft sequence and does not yet satisfy strict production animation continuity. No return stroke is included. The HTML preview plays once and stops at frame 16.
